# 연동 서버 설정 (Cloudflare Worker)

디스코드 알림 · Firebase 사용량 · 라이엇 솔랭 자동 갱신을 맡는 작은 서버입니다. 무료 플랜이면 충분하고, Node나 빌드 도구 없이 **브라우저에서만** 설정할 수 있습니다.
코드는 `worker.js` 한 파일입니다. 비밀값(웹후크 주소, 라이엇 키 등)은 사이트 코드에 넣지 않고 여기에만 둡니다.

설정은 아래 순서대로 하면 됩니다. 1~3단계는 미리 값을 받아 두는 단계라 어떤 순서로 해도 괜찮습니다.

## 1. 디스코드 웹후크 만들기 (러블리 승진이의 내전방)
1. 디스코드에서 **러블리 승진이의 내전방** 서버를 엽니다.
2. 채널 목록의 `＋`를 눌러 텍스트 채널을 하나 만듭니다. 예: `내전-알림`
3. 만든 채널 옆 톱니바퀴(채널 편집) → **연동** → **웹후크** → **새 웹후크**
4. 이름을 `내전 기록실`로 바꾸고(프로필 사진은 원하면 `og.png`나 로고 이미지), **웹후크 URL 복사**를 누릅니다.
   - 이 URL은 비밀번호처럼 다뤄 주세요. 채팅이나 GitHub에 올리지 말고 5단계에서 Worker에만 넣습니다.

## 2. 라이엇 API 키 받기
1. https://developer.riotgames.com 에 라이엇 계정으로 로그인합니다.
2. 첫 화면의 **Development API Key**(`RGAPI-…`)를 복사합니다. 테스트용으로 바로 쓸 수 있습니다.
   - ⚠️ 개발 키는 **24시간마다 만료**됩니다. 만료되면 자동 갱신이 멈추고, 관리 화면에서 "키가 만료됐어요"라고 나옵니다.
3. 계속 쓰려면 같은 사이트에서 **Register Product → Personal API Key**를 신청합니다. 승인되면 만료되지 않는 키가 나오고, 그 키로 바꿔 넣으면 됩니다.

## 3. Firebase 사용량 조회용 서비스 계정 만들기
1. Cloud Monitoring API 켜기: https://console.cloud.google.com/apis/library/monitoring.googleapis.com?project=lolnaejeonpot → **사용**
2. 서비스 계정 만들기: https://console.cloud.google.com/iam-admin/serviceaccounts/create?project=lolnaejeonpot
   - 이름: `usage-reader` → **만들고 계속하기**
   - 역할: **Monitoring 뷰어** (`Monitoring Viewer`) 하나만 고릅니다 → **완료**
     (이 권한으로는 사용량 숫자를 보는 것만 가능하고, 데이터는 읽거나 고칠 수 없습니다.)
3. 만든 계정을 눌러 **키** 탭 → **키 추가 → 새 키 만들기 → JSON** → 파일이 내려받아집니다.
   - 이 파일을 메모장으로 열어 **내용 전체**를 5단계에서 붙여 넣습니다. 붙여 넣은 뒤에는 파일을 지워도 됩니다.

## 4. Worker 만들기
1. https://dash.cloudflare.com → 왼쪽 **Workers 및 Pages** (Compute) → **만들기** → **Worker 만들기**
2. 이름을 `naejeonpot`으로 정하고 **배포**를 누릅니다(처음엔 예시 코드가 배포됩니다).
3. **코드 편집**을 누르고, 편집기 내용을 모두 지운 뒤 이 폴더의 `worker.js` 내용을 통째로 붙여 넣고 **배포**를 누릅니다.
4. 화면 위쪽의 주소(`https://naejeonpot.○○○.workers.dev`)를 복사해 둡니다.

## 5. 비밀값 넣기
Worker 화면 → **설정** → **변수 및 비밀** → **추가**

| 이름 | 종류 | 값 |
|---|---|---|
| `LEAGUE_KEY` | 비밀(Secret) | 초대 링크 `?k=` 뒤의 코드 |
| `DISCORD_WEBHOOK` | 비밀 | 1단계에서 복사한 웹후크 URL |
| `RIOT_KEY` | 비밀 | 2단계의 라이엇 키 |
| `GCP_SA` | 비밀 | 3단계 JSON 파일 내용 전체 |
| `SITE_URL` | 텍스트 | 디스코드 메시지의 "바로가기" 주소. 초대 링크 전체를 넣으면 눌러서 바로 들어올 수 있습니다 |
| `DISCORD_MENTION` | 텍스트 (선택) | 라인 지원 알림 때 부를 대상. 예: `@everyone` 또는 역할 멘션 `<@&역할ID>` |

다 넣고 **배포**를 누릅니다. 브라우저로 Worker 주소를 열면 `{"ok":true,"set":{...}}`처럼 각 값이 들어갔는지(`true`/`false`) 보입니다(값 자체는 나오지 않음).

## 6. 매일 자동 갱신 예약 (라이엇)
Worker 화면 → **설정** → **트리거** → **Cron 트리거 추가** → 아래 식을 넣고 저장

```
0,10,20 19 * * *
```

한국 시간 매일 **새벽 4시, 4시 10분, 4시 20분**에 실행됩니다(Cron은 세계 표준시 기준이라 19시 = 한국 오전 4시).
무료 플랜은 한 번 실행에 외부 요청을 50번까지만 할 수 있어서 세 번에 나눠 돌립니다. 이미 그날 갱신된 사람은 건너뛰므로 실제로는 **한 사람당 하루 한 번**입니다.

### 사용량 감시 (Blaze 요금제)
같은 화면에서 **Cron 트리거를 하나 더** 추가합니다.

```
*/30 * * * *
```

30분마다 Firebase 사용량을 확인해서 디스코드로 알려 줍니다.
- 오늘 읽기·쓰기·삭제 중 하나가 무료 한도의 **80%**를 넘으면 (항목마다 하루 한 번)
- 오늘 무료 한도를 넘어 **요금이 붙기 시작하면** (하루 한 번)
- 이번 달 요금이 지난 알림 때보다 **늘었으면**, 한국 시간 오전 9시 이후 하루 한 번 누적 금액

알림 기록은 Firestore `ops/alerts` 문서에 남깁니다. 사이트가 구독하지 않는 곳이라 접속자 화면의 읽기는 늘지 않습니다.

### 요금 단가 (선택)
사이트에 보이는 금액은 하루마다 무료 한도를 넘은 건수 × 단가로 계산한 **예상 금액**입니다. 기본 단가는 서울 리전 추정치(10만 건당 읽기 $0.038, 쓰기 $0.115, 삭제 $0.013)이고 환율은 1달러 1,400원입니다.
[Firestore 가격표](https://cloud.google.com/firestore/pricing)에서 서울(asia-northeast3) 값을 확인해 다르면, Worker 변수(텍스트)로 덮어씁니다: `RATE_READ`, `RATE_WRITE`, `RATE_DELETE`, `USD_KRW`. 실제 청구 금액은 [결제 콘솔](https://console.cloud.google.com/billing?project=lolnaejeonpot)에서 확인합니다.

## 7. 사이트에 Worker 주소 넣기
`js/config.js` 맨 아래의 `WORKER_URL`에 4단계 주소를 넣고 GitHub에 올립니다.

```js
export const WORKER_URL = 'https://naejeonpot.○○○.workers.dev';
```

GitHub 웹에서 파일을 열어 연필(✏️) 버튼으로 고치고 **Commit changes**를 눌러도 됩니다.

## 8. 확인
사이트 **관리** 화면 맨 위 "Firebase 사용량" 칸에서:
- 오늘 읽기·쓰기·삭제가 무료 한도 대비 몇 %인지, 최근 8일 읽기 막대가 나오면 사용량 조회 성공
- **디스코드 테스트 알림** → 채널에 "✅ 연동 테스트" 메시지가 오면 성공
- **라이엇 전적 지금 갱신**(관리자 PIN 필요) → "갱신 N명"이 나오고 선수 카드의 솔랭 티어·전적이 바뀌면 성공

## 동작 방식 (참고)
- **알림**: 사이트는 "라인 지원이 열렸다(문서 id)", "경기를 저장했다(경기 id)", "가챠에서 전설 이상 스킨을 뽑았다(선수 id-시각)"만 Worker에 알립니다. Worker가 Firestore에서 그 문서를 직접 읽어 확인한 뒤 메시지를 만들기 때문에, 누가 요청을 흉내 내도 없는 내용을 올릴 수 없습니다. 같은 알림은 두 번 보내지 않습니다.
- **사용량**: 구글 Cloud Monitoring 수치라 몇 분 늦게 반영됩니다. 결제 계정이 연결된(Blaze) 프로젝트에서만 동작합니다. Worker가 5분 동안 같은 값을 재사용하므로 여러 번 불러도 요금이 늘지 않습니다. 이 조회는 Firestore 읽기를 쓰지 않습니다. 관리 화면에는 게이지·예상 요금·최근 8일 막대가, 채팅창 머리(삭제 버튼 아래)에는 남은 무료 한도와 이번 달 예상 요금이 나옵니다.
- **라이엇 갱신**: 선수의 라이엇 ID(`이름#태그`, 여러 개면 첫 번째)로 솔랭 티어·LP·승패를 가져와 `soloTier`, `solo.record`, `solo.asOf`, `riot`에 적습니다.
  - 솔랭 티어는 내전 MMR 시작값에도 쓰이므로, 처음 갱신할 때 지금 시작값을 `mmrInit`에 고정합니다. 티어가 바뀌어도 그동안의 내전 MMR은 흔들리지 않습니다.
  - 라이엇 ID를 찾지 못한 선수는 관리 화면에 실패로 표시되고, 다음 날 다시 시도합니다.
  - 최고 티어·모스트 챔피언은 라이엇 API로 바로 알 수 없어서 지금처럼 직접 입력합니다.
- **요금**: Cloudflare 무료 플랜(하루 10만 요청) 안에서 충분합니다. Firestore는 알림 한 번에 몇십 건, 라이엇 갱신 하루 수십 건 정도의 읽기·쓰기만 늘어납니다.
